## 一、题目在考什么

用智能体把**自然语言 Spec** 一路打通到**可用版图尺寸**，且全程在国产 EDA 栈（Aether / PyAether / MDE / ALPS + PDK）上跑通。

链路：`自然语言 → spec.json → 拓扑模块识别 → 参数约减 → 多目标尺寸优化 → 反标 schematic_var_best → 全 PVT 仿真验证`

四个模块，两个部署域：

| # | 模块 | 部署 | 交付物 |
|---|---|---|---|
| 1 | 自然语言 Spec 解析（智能体） | 本地 | `spec.json`（硬约束 / 优化目标 / 单位 / 目标优先级） |
| 2 | 拓扑模块识别 + 参数约减（智能体） | 本地 | 识别结果 + 识别依据 + 约减后变量个数 + 变量统计表 + 约减后网表 |
| 3 | 基于约束的多目标尺寸优化 | 九天服务器 | 最优尺寸 / 最优反标电路图 / 全 PVT 验证报告 |
| 4 | PyAether 辅助自动化流程脚本 | 九天服务器 | 参数化脚本、连接关系读取、MDE 仿真引擎、反标脚本、`run_opt_command.sh` 集成接口 |

**约束速查（硬事实，勿记错）**

- 指标：`PM ≥ 50°`、`GM ≤ -10dB`、`I_OPA ≤ 3mA`、`DC Gain ≥ 40dB`，**全部 PVT 下成立**
- PVT 场景：工艺 `TT/FF/SS` × 温度 `-40℃ / 27℃ / 125℃` × 电源 `±10%`
- PDK：晶体管 `W 0.13–20µm`、`L 0.13–10µm`、`m 1..20 整数`；电阻 `Seg 1..20 整数`；电容 `L 0.13–20µm`
- 面积：MOS `f*w*L*m*1.5`、电容 `W*L*1`、电阻 `W*L*2`
- 单电路整体运行时间 **≤ 3 小时**
- LLM 指定 **Qwen 3.8-Max**，API Key 调用
- 样本：`Public` 电路 1 个（**不评分**）+ `Hidden` 电路 1 个（**评分**）

## 二、评分结构 → 战略含义（本节是题眼）

### 2.1 分数分布

| 项 | 6.3 原始分 | 折算(初赛) | 性质 |
|---|---|---|---|

| 拓扑识别 + 参数约减 | 10 | 7.0 | 每错 1 个约束扣 1 分 |
| 约束满足 PM | 10 | 7.0 | **全或无**，全 PVT |
| 约束满足 GM | 10 | 7.0 | **全或无**，全 PVT |
| 约束满足 I_OPA | 10 | 7.0 | **全或无**，全 PVT |
| DC Gain | 10 | 7.0 | 排名归一化，< 40dB 直接 0 |
| UGB | 15 | 10.5 | 排名归一化 |
| 面积 | 15 | 10.5 | 排名归一化，`A0/A1` |

初赛总分 = 报告 20 + 客观性能 70 + PyAether 问卷 10。

### 2.2 四条必须内化的结论

**① 约束是全或无，目标分是相对排名。**
Gain/UGB/Area 都按"别人成绩"归一化。达标只是入场券，**比对手强才得分**。这决定了优化器不能"刚好满足"，要在约束边界内做到极致。

**② DC Gain 是另外两项的前提。**
UGB 与 Area 的评分明确限定"在满足 DC Gain > 40dB 的前提下"。Gain 低于 40dB 会**三重损失**：Gain 项 0 分 + UGB 项失效 + Area 项失效。≈ 28 折算分。这是单项最大的雷。

**③ 违约代价被双重计费。**
PM 违规 ≈ 约束项 7 分 + 运行时间项再扣 3.5 分。因此优化器必须以**最坏 PVT 角**为约束判据，而不是 TT。只在 TT 调通、FF/SS 或 125℃ 崩掉，是这类赛题最典型的翻车方式。

**④ 速度本身是竞争力。**
`T0/T1 × 10`，3 小时硬上限。"能跑完"和"跑得快"要同时设计——这直接约束了仿真调用预算。

### 2.3 由评分反推的搜索空间策略

仿真预算 ≈ `PVT 角数 × 种群 × 代数`。假设全 PVT 取 `3 工艺 × 3 温度 × 3 电压 = 27` 个角，若每次 ALPS 仿真 `t` 秒、总预算 3 小时，则允许的仿真次数：

```
N_max = 10800 / t   （单角单次）
若每候选点需全 27 角验证：候选点数 ≈ 10800 / (27t)
```

`t = 10s` → 仅约 40 个完整候选点；`t = 60s` → 约 6 个。**结论：不可能对每个候选做全 PVT 仿真。**

可行架构必须是**分级筛选**：
1. TT 标称角粗筛（廉价，大种群）
2. 少数候选进入 PVT 最坏角校验（昂贵）
3. 用已仿真数据拟合代理模型（Gain/UGB/PM vs 尺寸），在代理上做大规模搜索，只回真仿真校验

这也解释了为什么**第②问的参数约减如此关键**：约减掉一半变量，代理模型的样本复杂度下降一个量级，直接决定能不能在 3 小时内收敛。

## 七、一句话总结

题目表面考三个智能体，实际考三件事：**通用性**（Hidden 电路上不硬编码）、**最坏情况思维**（全 PVT 而非 TT）、**算力预算管理**（3 小时内完成不可能的全 PVT 搜索，靠约减 + 分级筛选 + 代理模型）。评分规则里 DC Gain 是 UGB 与面积的前提，且约束项全或无、目标项按对手归一化——因此策略上必须"**先死守约束，再在可行域内压面积、拉带宽**"。
